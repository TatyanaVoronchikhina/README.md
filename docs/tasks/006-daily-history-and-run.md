# 006 — Дневная история и запуск на хосте

## Цель

Реализовать дневные агрегаты, HTTP-историю и воспроизводимый запуск на одном хосте.

## Зависимости и контракты

Зависит от задачи 005. [Дневные средние](../05-analytics.md), [OpenAPI history](../03-openapi.yaml), [эксплуатация](../04-data-and-operations.md#запуск). Библиотеки: `time`, `encoding/csv`, `sort`; decimal.

Термины задачи: **`aggregate-day`** — новая CLI-команда бинарника, закрывающая один завершённый день: читает снимки из `data/archive/YYYY-MM-DD/` и пишет дневные средние в `data/daily/YYYY-MM-DD.csv`. **Ключ группировки** — набор полей `date + source + kind + bank + city + channel + from + to` из [документа 05](../05-analytics.md); среднее считается отдельно для каждого такого набора, банки и каналы не смешиваются. **Дневное среднее (`average_rate`)** — арифметическое среднее направленных курсов внутри одного ключа группировки (формула в [документе 05](../05-analytics.md)).

## Объём работ

1. Добавить aggregate-day --date YYYY-MM-DD, по умолчанию вчера Europe/Moscow. Группировать по полному ключу из документа 05.
2. Считать среднее успешных наблюдений отдельно по направлению, источнику, банку и каналу; записывать daily CSV с sample_count атомарно. Исходные снимки сохранять для пересчёта.
3. Добавить GET /v1/rates/history с start/end и ошибками из OpenAPI.
4. Обновить README командами сборки и запуска, переменными окружения. Добавить data/, data-demo/ и бинарник в .gitignore.
5. Добавить crontab.example: import каждые 15 минут, aggregate-day в 00:10 Europe/Moscow; указать абсолютные пути, рабочую директорию, получение stdout и способ исключения перекрытия запусков.

## Критерии готовности

- [ ] Курсы 80 и 82 дают average_rate=81.000000, sample_count=2. Записи другого банка агрегируются отдельно; отсутствие наблюдения не считается нулём.
- [ ] UTC-время 21:15 относится к следующей московской дате. Текущий и будущий дни отклоняются.
- [ ] Повторная агрегация воспроизводима; повреждённый исходный CSV оставляет прежний daily-файл и ERROR.
- [ ] History возвращает дневные точки; отсутствующий день даёт 404.
- [ ] `go build ./...` и `go vet ./...` проходят. Сборка, команды и расписание воспроизводимы по README.
