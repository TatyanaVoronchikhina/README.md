# Валютный сервис на Go

Пакет требований для реализации сервиса сбора валютных курсов, конвертации, сравнения банковских предложений и хранения дневной истории.

Результат — один Go-бинарник, локальные CSV, JSON-логи в stdout и запуск фоновых команд через cron. Метрики и автоматические тесты в текущий объём не входят.
