# Валютный сервис на Go

Пакет требований для реализации сервиса сбора валютных курсов, конвертации, сравнения банковских предложений и хранения дневной истории.

Результат — один Go-бинарник, локальные CSV, JSON-логи в stdout и запуск фоновых команд через cron. Метрики и автоматические тесты в текущий объём не входят.

Все документы доступны сразу. Выполнять задачи 001–006 по порядку; конкретные требования и критерии готовности указаны в каждой карточке. Общие форматы и правила определены в соответствующих справочниках.

Код сервиса пока не реализован. Результаты прошлых проверок внешних API относятся к дате, указанной в каталоге источников.
